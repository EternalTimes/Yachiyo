# 安全、恢复与发布基线

状态：初稿；这是实现与验收基线，不代表已经通过安全审计。正式漏洞报告渠道在创建仓库后配置，不能虚构联系地址。

## 1. 默认行为

本地代理与控制接口默认仅监听 loopback。LAN 接入需要显式配置认证和访问范围。TLS 证书校验默认开启；测试例外必须显式标记，不能变为示例默认值。

配置、协议头、DNS 响应、订阅及控制 API 输入均不可信。限制体积、时间、递归、重定向与并发。解析失败返回可定位错误，不能 panic 后依赖外部重启。下载订阅和规则默认 HTTPS，校验证书，限制响应和重定向，并对跨主机重定向避免转发认证信息。

日志默认不写口令、令牌、完整订阅 URL 和私钥。域名 / IP / 进程路径可能包含隐私，诊断导出时分级脱敏。保留时长与最大体积可配置。管理接口不能返回原始凭据。

特权 helper 只提供有限操作，验证调用者和参数；不能接受任意命令或任意文件写入。普通转发与解析尽量保持普通权限。签名密钥与发布凭据仅在受控发布环境使用。

## 2. 网络行为与失败策略

默认“代理失败不自动改为直连”。DIRECT 只来自明确规则或显式配置的回退，DNS 解析失败也不隐式绕过既定策略。

显式代理模式不能保证所有应用流量都经过代理；TUN 模式的覆盖范围取决于路由、IPv6、DNS 和应用行为，必须写入限制。v0.2 默认失败策略提案为恢复系统原网络状态；持续阻断网络的 kill switch 是另一个功能，必须单独设计与验收。

系统修改前保存必要状态，标记拥有者与配置代际。正常退出主动恢复；异常中断由恢复入口或下次启动核对和清理。恢复前检查当前状态，避免覆盖第三方 VPN 或用户的新配置。

## 3. 版本与发布

使用 v0.x.y 预发布阶段编号；0.x 仍应说明所有不兼容变化，不能以未到 1.0 为由隐瞒迁移成本。配置 schema 与控制 API 独立版本化。每个发布记录代码提交、工具链、依赖、构建方式、变更和已知问题。

每项宣称支持的能力都有测试证据。平台标签区分“能编译”“已烟测”“已日常验证”，只对最后两者说明具体支持级别。个人本地构建与面向他人的正式分发区分；macOS 签名、公证及 entitlement 要求按最终打包方式验证。

发布必须具备：可追溯产物、校验和、许可证及第三方声明、基础依赖清单、配置示例、迁移与回退说明。构建可复现程度逐步测量，未验证前不宣称字节级可复现。

许可证按 AGPL-3.0-only 执行。二进制发布同时提供符合许可证要求、与版本匹配的对应源码及构建脚本；修改版提供远程网络交互时，向相应用户显著提供获取对应源码的机会。源码入口设计及验收纳入首个可运行版本，不以链接到无版本对应关系的仓库首页代替。保留原许可证及第三方声明，详见 [许可证说明](LICENSING.md)。

## 4. 发布阻断条件

以下问题阻断对应版本：数据错误或连接无界泄漏；认证或证书校验绕过；凭据暴露；配置失败破坏旧实例；目标能力的必需检查未通过；许可证义务未履行。

涉及系统网络修改的版本还需阻断：启动失败留下不可恢复路由 / DNS；正常停止恢复失败；崩溃后缺少可用恢复入口；IPv4 / IPv6 行为与所宣称范围不符。

高风险问题先停发或撤回受影响版本，提供回退与用户说明。漏洞渠道启用后优先私下提交可复现材料，公开说明不包含用户凭据或真实访问记录。

## 5. 实机验收最小集合

| 场景 | 验收证据 |
| --- | --- |
| 启动、停止、重复启动 | 端口、文件描述符与相关系统状态符合预期 |
| 配置无效、端口占用、认证失败 | 错误可定位，旧运行状态按契约保留 |
| 服务端超时、断网与网络切换 | 重试有界，无连接堆积，不触发隐式直连 |
| 睡眠唤醒 | 已声明支持的连接恢复策略生效 |
| 强制退出与重新启动 | 恢复日志可核对，旧状态可清理 |
| IPv4 / IPv6、DNS 与其他 VPN 共存 | 实测与支持矩阵一致，无法覆盖的场景明确披露 |
